# NUAGE hero photographs

Drop the original, licensed, high-resolution files here, then run `npm run images`.
They are trimmed, resized and converted to AVIF + WebP in `public/hero/nuage/`.
Any photo not supplied yet is simply left out of the hero.

All files must be **cut-outs with a transparent background** (PNG, WebP, AVIF or TIFF).
The hero adds the dark-chocolate set, lighting and shadows itself.

| File name           | Subject                                              | Min. width |
| ------------------- | ---------------------------------------------------- | ---------- |
| `croissant`         | Hero croissant, ¾ angle, warm side light, crisp flakes | 2400 px  |
| `chocolate`         | Molten dark chocolate pour / ribbon falling from top  | 1400 px   |
| `raspberry-a/-b/-c` | Single raspberries, three different angles            | 800 px    |
| `flake-a/-b/-c`     | Individual croissant / pastry flakes                  | 600 px    |

Keep licences (receipts or licence PDFs) alongside the originals.
